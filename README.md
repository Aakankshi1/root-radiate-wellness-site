# Root & Radiate Wellness Website

Static HTML/CSS/JS website for Root & Radiate Wellness.

## Pages
- Home
- About
- Instructor
- Programs
- Testimonials
- Weekend Retreats
- Shop
- Contact

## Local preview
Open `index.html` in a browser.

## Deploy
Push this folder to GitHub, then deploy the repository to Hostinger using hPanel Git deployment or upload the ZIP contents into `public_html`.


## Gallery page

`gallery.html` has been added to the navigation. Real photos can be placed in `assets/gallery/` and the placeholder blocks in `gallery.html` can be replaced with image tags.
